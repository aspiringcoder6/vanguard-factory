# Gọi tool MCP — ví dụ nhanh

## Mục đích

Giao việc cho Workloop bằng ngôn ngữ tự nhiên qua agent orchestrator. Trang này chỉ chứa **cách dùng
hàng ngày** của MCP `workloop-factory`; bảng tra đầy đủ (tham số, trả về) nằm ở
[MCP Tools Reference](/docs/reference/mcp-tools) — theo quy tắc "một chỗ duy nhất".

## Điều kiện trước

- MCP server `workloop-factory` đã cắm cho orchestrator với `WORKLOOP_URL` + `WORKLOOP_TOKEN` +
  `FACTORY_REPO_URL`/`FACTORY_PATH` — [Cài đặt, bước 4](/docs/user-guides/workloop-dieu-phoi/cai-dat#bước-4-cắm-mcp-cho-agent-orchestrator).

## Năm tool hay dùng nhất

| Tool | Khi nào dùng |
|---|---|
| `configure_workflow` | Định nghĩa/cập nhật workflow — ghi factory repo, trả `version` + `sha` |
| `run_workflow` | Chạy workflow — trả `job_id`; `fresh=true` chạy lại sạch sau khi sửa spec |
| `get_run` | Xem trạng thái run (node nào xong, node nào chờ, events lỗi) |
| `get_report` | Xem sản phẩm từng node — tin nhắn cuối của agent (Status/commits/test/concerns) |
| `resume_run` | Chạy tiếp run đang suspended (sau PAUSE) từ checkpoint — node đã xong không chạy lại |

Tool hỗ trợ còn lại: `pause_run` (PAUSE/STOP) · `list_workflows`/`get_workflow` (workflow đã đăng
ký) · `list_runs` · `record_pr` (track PR vào vòng đời) · bộ `confluence_*` (tìm/đọc/tạo/sửa trang).

:::note[Không dùng `call_agent` thay workflow]

`call_agent` chỉ gọi được **agent tĩnh** (ví dụ `spec` — soạn tài liệu thiết kế, bắt buộc
`doc_type`: `ptyc`/`tkct`/`tkcsdl`). Worker thật (coder, reviewer…) chạy qua workflow theo `role`
trong spec — muốn chạy việc, đi theo [Vòng 4 bước](/docs/user-guides/workloop-dieu-phoi/vong-4-buoc).

:::

## Ví dụ — một câu cho agent orchestrator

```text
Dùng MCP workloop-factory: configure_workflow tạo workflow 'hello2' với 1 node hello
(type WorkloopTask, role coder, brief: viết reports/hello.md 1 dòng 'hello world').
Sau đó run_workflow('hello2', fresh=true) và in job_id.
```

Agent orchestrator sẽ gọi chuỗi tool và trả về `job_id` — bạn theo dõi bằng `get_run` hoặc tab
**Runs**. Vòng làm việc đầy đủ: [Vòng 4 bước](/docs/user-guides/workloop-dieu-phoi/vong-4-buoc).

## Kết quả đúng phải thấy

Câu lệnh trên hoàn tất mà không lỗi; `get_run(job_id)` cho node ở trạng thái terminal
(`DONE`) và `get_report(job_id)` có tin nhắn cuối của agent.

## Lỗi thường gặp

| Hiện tượng | Xử lý |
|---|---|
| Tool báo lỗi kết nối backend | kiểm tra `WORKLOOP_URL` + `WORKLOOP_TOKEN` trong cấu hình MCP |
| `configure_workflow` trả lỗi validate | spec sai — sửa theo thông báo lỗi (validate fail-loud, chưa ghi gì vào factory repo); cú pháp: [Spec DSL](/docs/reference/spec-dsl) |
| Gọi `call_agent` nhưng việc không chạy như kỳ vọng | đúng cơ chế — worker thật chỉ chạy qua workflow; đi [Vòng 4 bước](/docs/user-guides/workloop-dieu-phoi/vong-4-buoc) |
